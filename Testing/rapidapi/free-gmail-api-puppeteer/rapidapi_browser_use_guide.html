RapidAPI từ GitHub đến kết quả key|name

Một quy trình kiểm thử có thể quan sát, dùng biến môi trường để bảo vệ thông tin đăng nhập và tạo mã TOTP ngay trên máy local.

Không chạy request API
01 / AUTH
GitHub OAuthĐăng nhập và xử lý mã TOTP.
02 / PLAN
Basic Free PlanChọn gói $0.00 và xác nhận Subscribe.
03 / OUTPUT
PlaygroundĐọc key và GitHub username.

Luồng thao tác

  1. Mở RapidAPI
    Vào trang login và chọn Login with Github.
  2. Xác thực GitHub
    Điền tài khoản, nhập OTP hiện tại nếu được hỏi.
  3. Chấp thuận OAuth
    Chỉ chấp thuận ứng dụng RapidAPI với quyền email read-only.
  4. Đăng ký Basic
    Mở pricing, chọn Basic, Start Free Plan, rồi Subscribe.
  5. Mở Playground
    Chọn Get Started hoặc Open playground.
  6. In kết quả
    Đọc X-RapidAPI-Key và username, in key|name.

Chạy local

Đặt bốn giá trị thật vào file .env cạnh script.

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
python rapidapi_flow.py

✓ Script dùng pyotp; không cần gửi seed lên twofa.co.

Bảo vệ tài khoản

Chỉ dùng với tài khoản bạn sở hữu hoặc được ủy quyền. Không ghi password, seed TOTP hoặc API key vào source code, Git, ảnh chụp màn hình hay log model.

Captcha, passkey hoặc bước xác minh bất thường nên được xử lý thủ công trên cửa sổ trình duyệt. Nếu OTP hết hạn, chạy lại với mã mới. Sau khi demo, hãy thu hồi key nếu không còn cần.

Các file đi kèm

rapidapi_flow.py là script Browser Use. README.md có hướng dẫn và khắc phục lỗi. rapidapi.env.example chỉ là mẫu cấu hình. requirements.txt chứa dependency.

Script không thực hiện cuộc gọi API; nó chỉ đăng ký gói và đọc thông tin hiển thị trong Playground.
