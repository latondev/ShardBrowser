Test đăng nhập WaveSpeed local, có kiểm tra tài khoản GitHub bị hạn chế

Thư mục tải xuống kèm theo trang này có script wavespeed-github-oauth-check.mjs. Script dùng một profile Chrome riêng, để bạn đăng nhập và nhập 2FA thủ công ở lần đầu. Nó không cố vượt qua hạn chế của GitHub.

Quan trọng: API key có toàn quyền inference và billing. Không đưa password, mã TOTP hoặc API key vào mã nguồn, Git, ảnh chụp màn hình hay tin nhắn công khai.

1. Chuẩn bị local

  1. Cài Node.js 20.6+ trên máy của bạn để dùng được --env-file.
  2. Tạo thư mục mới, ví dụ wavespeed-puppeteer-test.
  3. Đặt hai file tải xuống vào cùng thư mục: wavespeed-github-oauth-check.mjs và .env.example.
  4. Đổi tên .env.example thành .env. File này chỉ chứa cấu hình local, không commit lên Git.
npm init -y
npm install puppeteer
node --version

2. Chạy test detector trước

Test này không mở trình duyệt và không cần tài khoản. Nó xác nhận script nhận diện đúng thông báo GitHub: “This account is flagged, and therefore cannot authorize a third party application.”

node wavespeed-github-oauth-check.mjs --test-flagged-detector

Kết quả mong đợi là hai dòng pass: true: một case bị đánh dấu và một case OAuth bình thường.

3. Chạy luồng OAuth bình thường

Chạy lần đầu không tạo API key. Chrome sẽ mở ra. Nếu GitHub yêu cầu email, password hoặc 2FA, hãy nhập thủ công trong cửa sổ đó.

node --env-file=.env wavespeed-github-oauth-check.mjs
  1. WaveSpeed mở trang đăng nhập.
  2. Script chọn Sign in with GitHub.
  3. Bạn hoàn tất đăng nhập và 2FA trong trình duyệt.
  4. Nếu GitHub hiện Authorize WaveSpeedAI, script bấm ủy quyền.
  5. Script xác nhận đã tới dashboard WaveSpeed.
WAVESPEED_LOGIN_OK
Đây là kết quả thành công. Profile được giữ ở .puppeteer-profile để các lần sau không phải đăng nhập lại.

4. Kiểm tra case tài khoản bị GitHub hạn chế

Không thể giả lập quyền hạn GitHub bằng cách bấm thêm nút hoặc đổi URL. Hãy dùng một tài khoản test đã bị hạn chế, hoặc chỉ chạy detector test ở bước 2.

  1. Chạy script như bước 3 với profile đang đăng nhập tài khoản test bị hạn chế.
  2. Khi GitHub hiển thị thông báo hạn chế, script dừng ngay.
  3. Kết quả sẽ là BLOCKED_ACCOUNT_FLAGGED.
  4. Ảnh bằng chứng được lưu tại artifacts/github-account-flagged.png.
BLOCKED_ACCOUNT_FLAGGED
Không retry liên tục, không tìm cách bypass OAuth. Chủ tài khoản cần dùng luồng hỗ trợ/kháng nghị của GitHub hoặc dùng tài khoản hợp lệ khác.

5. Tạo key mới khi bạn thật sự cần

Mặc định script không tạo key để tránh tạo nhiều key ngoài ý muốn. Chỉ chạy lệnh dưới đây một lần khi bạn đã kiểm tra OAuth thành công.

node --env-file=.env wavespeed-github-oauth-check.mjs --create-key

Key chỉ in ra terminal một lần. Lưu nó vào secret manager hoặc file local không commit. Đừng chạy lại cờ --create-key nếu chưa cần key khác.

6. Các trạng thái script

OAUTH_CONSENT

GitHub đã tới trang xin quyền WaveSpeed. Script sẽ ủy quyền.

WAVESPEED_CALLBACK

App đã được ủy quyền từ trước và GitHub chuyển thẳng về WaveSpeed.

WAVESPEED_LOGIN_OK

Đã quay về dashboard WaveSpeed.

BLOCKED_ACCOUNT_FLAGGED

GitHub không cho tài khoản ủy quyền ứng dụng bên thứ ba.

TIMEOUT

Chưa hoàn tất đăng nhập hoặc 2FA trong thời gian chờ.

API_KEY_CREATED

Đã tạo key khi chạy với --create-key.

7. Lỗi thường gặp

  • Browser không mở: chạy lại npm install puppeteer và kiểm tra Node.js.
  • Hết thời gian: hoàn tất đăng nhập/2FA trong cửa sổ Chrome; không đóng cửa sổ trước khi có kết quả.
  • Không thấy nút Authorize: kiểm tra xem GitHub có đang ở trang login hay đang hiện thông báo hạn chế.
  • Key dùng không được: dashboard hiện số dư $0; cần nạp credit theo tài khoản trước khi gọi model.
  • Muốn đổi tài khoản: đóng script rồi dùng profile riêng khác, không xóa nhầm profile Chrome cá nhân.
File script đi kèm không chứa thông tin đăng nhập. Dùng tài khoản test và tuân thủ điều khoản của GitHub, WaveSpeed.
